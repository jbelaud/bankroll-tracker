# Démonstration Kalivoa Scan — storyboard Wave 1

## Statut

Préparée, sans vidéo publiée à ce stade. L'enregistrement reste facultatif
pendant la Wave 1 : il ne doit utiliser qu'un parcours réel et validé.

## Garde-fous

- format vertical 9:16, mobile prioritaire ;
- durée cible : 8 à 10 secondes ;
- utiliser uniquement des tickets réellement importés pendant un test ;
- masquer nom, solde, identifiants, référence sensible et toute donnée
  personnelle avant enregistrement ;
- ne pas monter un résultat préparé artificiellement, ni afficher un taux de
  réussite non mesuré.

## Storyboard

| Temps | Écran / action réelle | Texte incrusté |
| --- | --- | --- |
| 0–1 s | Écran Scan, capture Winamax réelle prête à être sélectionnée | `4 paris. Zéro saisie.` |
| 1–3 s | Sélection des captures puis démarrage de Kalivoa Scan | `Kalivoa lit tes tickets.` |
| 3–5 s | Résultat d'analyse et passage par l'écran de vérification | `Tu vérifies. Tu gardes le contrôle.` |
| 5–7 s | Import confirmé | `Importés dans ta bankroll.` |
| 7–9 s | Dashboard / historique avec les nouveaux paris | `Tes paris. Tes stats. Zéro saisie.` |

CTA final : `Teste Kalivoa Scan — beta.kalivoa.com` ne doit **pas** être
utilisé. Utiliser exactement : `kalivoa.com`.

## Procédure d'enregistrement

1. Ouvrir `https://kalivoa.com/fr/scan` sur téléphone et vérifier que la
   bankroll concernée est sélectionnée.
2. Préparer la capture Winamax réelle ayant permis d'importer 4 paris sans
   correction. Masquer les données sensibles si nécessaire.
3. Démarrer l'enregistrement d'écran juste avant d'ouvrir le sélecteur de
   captures.
4. Sélectionner les captures, lancer Kalivoa Scan, puis montrer très brièvement
   la vérification obligatoire.
5. Corriger uniquement si une correction réelle est nécessaire ; sinon importer
   directement les paris proposés.
6. Terminer sur le dashboard ou l'historique mis à jour, puis arrêter
   l'enregistrement.
7. Transmettre la vidéo brute et préciser le bookmaker, le nombre de captures,
   le nombre de paris importés et les éventuelles corrections. Le montage pourra
   retirer les temps d'attente et masquer les données restantes.

## Variantes de hook à tester ultérieurement

- `Tu rentres encore tes paris un par un ?`
- `4 paris à ajouter. Aucun à saisir.`
- `Screenshot tes paris. Kalivoa fait le reste.`

Le premier test doit conserver un seul hook : `4 paris. Zéro saisie.` C'est
le seul résultat déjà validé en conditions réelles ; les volumes supérieurs
ne doivent être utilisés qu'après une démonstration équivalente.
